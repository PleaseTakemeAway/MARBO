# Academic Paper Project Page Starter

This is a simple static project page designed for GitHub Pages.

## 1. Edit the content

Open `index.html` and search for `TODO`.

Replace:

- paper title
- authors and affiliations
- conference
- Paper / arXiv / Code / Dataset links
- TL;DR
- abstract
- method description
- result description
- BibTeX

## 2. Replace figures

Replace files in `static/images/` or change the corresponding paths in `index.html`.

Recommended:

- teaser: PNG, JPG, WebP, or SVG
- method figure: PNG, JPG, WebP, or SVG
- results: PNG, JPG, WebP, or SVG

## 3. Preview locally

Double click `index.html`, or in VS Code use the Live Server extension.

## 4. Push to GitHub

```cmd
git init
git add .
git commit -m "Initial project page"
git branch -M main
git remote add origin https://github.com/YOUR_ID/YOUR_REPO.git
git push -u origin main
```

## 5. Enable GitHub Pages

Repository > Settings > Pages > Deploy from a branch > `main` > `/root` > Save

The page will normally be available at:

`https://YOUR_ID.github.io/YOUR_REPO/`

## Suggested page order

1. Title and authors
2. Resource buttons
3. Teaser
4. TL;DR
5. Abstract
6. Method
7. Key contributions
8. Main results
9. BibTeX
