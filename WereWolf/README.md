# Wolf

This directory contains the code for the Wolf project, featuring a Text-Based Werewolf environment and its associated agents.

## Installation

We recommend using `uv` for dependency management. Follow these steps to set up the project:

1. **Create a virtual environment:**
   Generate your virtual environment using Python 3.10:
   ```bash
   uv venv myvenv --python 3.10
   ```

2. **Activate the virtual environment:**
   - On Windows: `myvenv\Scripts\activate`
   - On macOS/Linux: `source myvenv/bin/activate`

3. **Install the package:**
   Install the package in editable mode:
   ```bash
   uv pip install -e .
   ```
